# Design Elements

## 1. Color Palette

* Primary Background Color: `#d9641f` (Rich Sunset Orange/Amber)
* Primary Text & Accent Color: `#fdcb7b` (Warm Sunny Yellow/Gold)

---

## 2. Typography Stack

* Display & Heading Font: Yeseva One (Used for prominent titles, branding, and major section headers, giving an organic, artisanal feel).
* Primary UI & Subheadings: League Spartan (Used for clean structural headers, stepper navigation, and button labels).
* Body & Form Text:** Garet (Used for all instructional paragraphs, input fields, and questionnaire prompts to ensure high legibility at smaller sizes).

---

## 3. Layout & Screen Architecture
### The 5-Screen Wizard Flow:
1. **Language Selection:** Instant choice between English, Spanish, Mandarin, and Hindi.
2. **Path Selection:** Tuff permit route vs. Agricultural / Raw Produce exemption triage.
3. **Questionnaire:** Clean, reactive input fields mapped directly to county PDF fields.
4. **Review:** Summary of all entered responses with error checking and script validation.
5. **Download & Done:** Generates the flattened official PDF directly on the vendor's device, followed by safe state-wiping.
